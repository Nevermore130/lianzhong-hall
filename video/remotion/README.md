# 游戏大厅交互宣发视频

Remotion 独立工程，输出 34 秒、1080 × 1920、30 fps 的竖屏视频。完整保留 Windows 98 大厅和原有棋牌素材，以指针操作、选中反馈、合法走子和出牌过程组织画面，配简短中文字幕、原创合成配乐和操作音效。

## 预览与导出

从本目录运行，主项目需先安装依赖：

```sh
npm ci
npm run check
npm run studio
npm run render
```

Studio 使用端口 5190，不占用游戏开发端口。首次导出会下载 Remotion 使用的 Chrome Headless Shell。仅检查关键画面时运行 `npm run stills`。

输出位于项目根目录的 `artifacts/xiaohongshu-remotion/`：

- `复古棋牌大厅-交互演示-Remotion.mp4`：H.264 / AAC 成片，中文字幕已烧录。
- `封面.jpg`：取自麻将碰牌后的实际画面。
- `字幕.srt`：单独字幕，供后续剪辑调整；成片已有字幕，发布时无需重复导入。
- `render-info.json`：导出参数。
- `frame-*.png`：关键帧预览，仅在运行 `stills` 后生成。

## 内容与真实性

| 时间         | 画面与操作                                         |
| ------------ | -------------------------------------------------- |
| 0–10.3 秒    | 大厅选游戏、进桌、入座、准备，五子棋双方连续落子   |
| 10.3–17 秒   | 中国象棋选棋子、显示合法位置、走炮和马             |
| 17–24.1 秒   | 斗地主叫三分、提示选牌、滑动手牌、出顺子、电脑应对 |
| 24.1–32.3 秒 | 中国麻将对手打红中、碰牌、选西风弃牌、轮转         |
| 32.3–34 秒   | 返回大厅，以“你最想和谁来一局？”收尾               |

这是使用项目真实组件和规则引擎制作的**交互重放**，不是服务器联机过程的连续录屏。人物、房间、时间及发牌固定用于可重复导出；视频不连接后端、不发送聊天消息，也不修改账号或战绩。象棋、斗地主、麻将展示的是现有单机练习界面。

`scripts/check-story.ts` 检查合法操作、手牌数量、碰牌/弃牌结果及完整的 136 张麻将牌。所有局面变化调用 `shared/` 内现有规则代码，不凭画面伪造走法。

## 修改方式

- `发布文案.md`：小红书笔记标题、正文和话题。
- `src/story.ts`：交互时间、字幕、指针目标、局面推进。
- `src/InteractionFilm.tsx`：视频中的客户端组合、指针与点击反馈、按帧滑动。
- `src/video.css`：仅在视频生效的尺寸、弹窗和字幕样式。
- `scripts/make-audio.ts`：原创合成背景音和点击音。
- `scripts/render.ts`：编码参数、关键帧和导出文件。

`prepare:video` 将应用 CSS 按 450 × 800 视口解析，再以 2.4 倍输出。大厅、棋盘、扑克牌和麻将牌复用当前项目组件及本地素材。需要受控选中状态的组件由脚本在 `.generated/` 生成适配副本，不修改生产组件。`.generated/`、依赖和成片不纳入 Git；修改原组件后重新运行上述命令即可刷新。

该目录有独立依赖和锁文件，主应用的构建、测试和服务器运行方式保持原样。
